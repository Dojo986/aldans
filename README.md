# Konfirmationsplan for Tea

Statisk web-GUI der hjælper med at holde styr på opgaver til konfirmationen den 16. maj 2026.

## Sådan bruger du siden

1. Åbn `index.html` i en browser.
2. Tilføj egne opgaver og noter.
3. Alt gemmes lokalt i browseren (localStorage).

## Lokal server (valgfri)

Hvis du vil køre siden via en simpel server:

```bash
python -m http.server 8000
```

Gå derefter til <http://localhost:8000>.
